Bulk upload — Projects & Tasks

← Back to Projects & Tasks

Projects is a name column plus an optional Department column — leave Department blank for a project every department can use, or list the same project on more than one row to restrict it to more than one department. Tasks is two columns — one row per Task + Project pair (see its template for why). Both are add-only: a value/link already on the list is skipped, not duplicated; nothing here renames or deactivates a value.

Projects / Employers

Columns: Project / Employer Name and an optional Department (leave blank for every department to use it; list the same project on more than one row to link it to more than one department).

Download blank template Download current list

Tasks

Columns: Task Name and Project Name (must match an existing project exactly — the template includes a Projects sheet to check against). One row per task+project pair; list the same task on more than one row to link it to more than one project.

Download blank template Download current list

Company Names

Column: Company Name. Add-only — a name already on the list is skipped, not duplicated. Once uploaded, employees can pick (or search) any of these from the Company field on a Case Type project's Today entry form.
